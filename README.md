# grua-empreendimentos
Desenvolvimento de uma Landing Page responsiva da Grua Empreendimentos, plataforma de construção civil e empreendimentos. Desenvolvida com foco em UI/UX: navbar com CTAs de cadastro e login, hero section com título de impacto, botão “Como funciona” e ilustração temática, fundo com guindastes e paleta laranja e azul-petróleo.
