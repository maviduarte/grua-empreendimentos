# 🏗 Grua Emprendimentos - Landing Page

Landing page responsiva da **Grua Empreendimentos**, plataforma voltada à construção civil e a empreendimentos. O projeto foi desenvolvido com foco em **UI/UX**, buscando transmitir solidez, profissionalismo e clareza logo no primeiro contato do visitante.

## 📌 Sobre o projeto

A Grua Empreendimentos conecta pessoas e negócios ao universo da construção civil. Esta landing page é a porta de entrada da plataforma: apresenta a marca, explica a proposta de valor e conduz o usuário para as ações principais, como **cadastro** e **login**.
